# Student Management System

A simple Student Management System built using Python and Microsoft SQL Server.

## Technologies Used

- Python
- Microsoft SQL Server
- pyodbc

## Project Description

This project connects a Python application with a SQL Server database to manage student-related data.

The Python program handles the application logic, while SQL Server is used to store and manage the database.

## Project Files

- `main.py` - Python application
- `database.sql` - SQL database and table queries
- `.gitignore` - Files ignored by Git

## Features

- Connect Python with SQL Server
- Manage student data
- Perform database operations using SQL
- Execute SQL queries from the Python application
